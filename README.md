# Capability–Object–Value Ontology (COVO)

This repository contains the OntoUML specification of the Capability–Object–Value Ontology (COVO) and its extension.

- **v1**: Original COVO (semantic triad) as published in  
  Severin, S., Roelens, B., Roubtsova, E., Sales, T.P., van der Knaap, T., Joosten, S.  
  *Semantically coherent business architecture models: Integrating capabilities, value streams, and business objects.*  
  18th IFIP WG 8.1 Working Conference on the Practice of Enterprise Modeling (PoEM 2025).  
  CEUR‑WS Vol. 4171, Paper 41.  
  https://ceur-ws.org/Vol-4171/paper_41.pdf

- **v2**: Extended COVO introducing *semantic symmetry* and formal constraints for intra‑perspective coherence between capability, value stream, and object dependencies.
